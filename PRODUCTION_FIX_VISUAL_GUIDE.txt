COMMON MISTAKES TO AVOID
═══════════════════════════════════════════════════════════════════════════════

❌ MISTAKE 1: Only setting frontend variables
   Problem: Backend doesn't know where database is
   Fix: Set BOTH frontend AND backend variables

❌ MISTAKE 2: Forgetting to redeploy after adding variables
   Problem: Old code still running
   Fix: Go to Deployments → Redeploy on latest

❌ MISTAKE 3: Using localhost URL in production
   Problem: localhost doesn't exist on Vercel cloud
   Fix: Use full HTTPS URL: https://merelosjeff-portfolio-backend.vercel.app

❌ MISTAKE 4: Committing .env to GitHub
   Problem: Secrets exposed publicly
   Fix: .env is in .gitignore (don't commit)
        Set variables on Vercel dashboard only

❌ MISTAKE 5: Copying from .env.local to Vercel without updating
   Problem: .env.local has localhost URLs (development)
   Fix: Use production URLs when setting Vercel variables
