DATABASE SCHEMA:
================================================================================

Table: contact_messages
Columns:
  - id (SERIAL, auto-generated)
  - name (VARCHAR 150, required)
  - email (VARCHAR 150, required, validated)
  - subject (VARCHAR 255, optional)
  - message (TEXT, required)
  - ip_address (VARCHAR 45, auto-captured)
  - status (VARCHAR 20, default 'unread')
  - created_at (TIMESTAMP, auto-set)
  - read_at (TIMESTAMP, nullable)

TROUBLESHOOTING:
================================================================================

Problem: Network Error - net::ERR_CONNECTION_REFUSED
  Cause: Backend server not running
  Fix: Start backend with "npm run dev" in /backend folder

Problem: Email validation keeps failing
  Cause: Invalid email format
  Fix: Use format: name@domain.com

Problem: Message won't submit
  Cause: Validation errors (check red messages below fields)
  Fix: Correct each field error

Problem: Backend starts but gives database error
  Cause: .env file missing or incorrect
  Fix: Copy .env.example to .env and fill in your values
