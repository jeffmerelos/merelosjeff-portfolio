                        IF SOMETHING GOES WRONG
================================================================================

Problem: "Network Error" when submitting
Solution: Make sure backend is running with "npm run dev" in /backend

Problem: Email validation error keeps showing
Solution: Use format name@domain.com (must have @ and a dot)

Problem: Backend won't start
Solution: Check .env file has SUPABASE_URL and SUPABASE_KEY

Problem: Frontend won't start
Solution: Check you're in /frontend folder, run "npm install" if needed

Can't find the answer? Check CONTACT_FORM_FIX_SUMMARY.txt (Troubleshooting section)
